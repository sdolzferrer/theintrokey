Esta guía paso a paso proporciona las soluciones detalladas para los ejercicios propuestos, diseñadas para facilitar un **aprendizaje significativo** en alumnos de ASIR, integrando los conocimientos del manual del curso y los estándares de certificación del Linux Professional Institute (LPI).

# Guía de Soluciones: Automatización y Shell Scripting Para todos los scripts, es fundamental recordar que un script es un archivo de texto que el sistema interpreta como un programa 1, 2\. El proceso general para cada ejercicio debe ser: 1\. Crear el archivo (ej. nano script.sh). 2\. Escribir el código con el **shebang** correspondiente. 3\. Guardar y asignar **permisos de ejecución** con chmod \+x script.sh 3, 4\. \--- \#\#\#\# Ejercicio 1: Gestión de Procesos y Entorno **Objetivo:** Identificar procesos de un usuario y manipular el PATH 5\. \* **Paso 1: Definir el intérprete.** Inicie con \#\!/bin/bash 1\. \* **Paso 2: Capturar el argumento.** Use $1 para recibir el nombre de usuario 6\. \* **Paso 3: Validar existencia.** Use id para verificar si el usuario existe en el sistema 7, 8\. \* **Paso 4: Modificar el entorno.** Añada el directorio de forma temporal a la variable PATH 9, 10\. **Solución monitor\_procs.sh:** bash \#\!/bin/bash \# Script para monitorear procesos de un usuario específico \[5\] USUARIO=$1 if id "$USUARIO" \>/dev/null 2\>&1; then echo "Procesos actuales para el usuario: $USUARIO" ps \-u "$USUARIO" \-o user,comm \[5, 11\] \# Añadir bin local al PATH temporalmente \[12, 13\] export PATH="$PATH:\~/bin" echo "PATH actualizado temporalmente: $PATH" else echo "Error: El usuario $USUARIO no existe en /etc/passwd" \[5, 14\] exit 1 fi  \--- \#\#\#\# Ejercicio 2: Auditoría de Seguridad y Filtrado **Objetivo:** Buscar archivos SUID pertenecientes a root y generar un informe 15\. \* **Paso 1: Búsqueda avanzada.** Use find con el parámetro \-perm para localizar el bit SUID (4000) 16, 17\. \* **Paso 2: Filtrado y Redirección.** Use una tubería (|) hacia grep y el operador \>\> para añadir datos al informe sin borrar lo anterior 18, 19\. \* **Paso 3: Verificación.** Imprima $? para confirmar que la operación se realizó con éxito 20, 21\. **Solución auditoria\_suid.sh:** bash \#\!/bin/bash \# Auditoría de archivos con bit SUID de root \[15, 22\] echo "Iniciando auditoría de seguridad..." find /usr/bin \-perm \-4000 \-user root | grep "root" \>\> \~/informe\_seguridad.txt \[15, 23\] if \[ $? \-eq 0 \]; then echo "Informe actualizado correctamente. Código de salida: $?" \[15, 24\] else echo "Hubo un problema durante la búsqueda." fi  \--- \#\#\#\# Ejercicio 3: Lógica DevOps y Bucles **Objetivo:** Verificar dependencias de software mediante una matriz y estructuras de control 25\. \* **Paso 1: Declarar la matriz.** Use la sintaxis de paréntesis para definir la lista de paquetes 26, 27\. \* **Paso 2: Iterar.** Use un bucle for para procesar cada elemento 28, 29\. \* **Paso 3: Lógica de selección.** Use case para gestionar los mensajes según el estado de instalación 30, 31\. **Solución check\_dependencies.sh:** bash \#\!/bin/bash \# Simulación de verificación de dependencias (SBOM) \[25\] PAQUETES=(curl git python3 figlet) \[26, 32\] for PKG in "${PAQUETES\[@\]}"; do if which "$PKG" \>/dev/null 2\>&1; then ESTADO="instalado" else ESTADO="faltante" fi case $ESTADO in "instalado") echo "Software: $PKG \- OK: Instalado" \[25, 31\] ;; "faltante") echo "Software: $PKG \- Faltante \- Alerta DevOps" \[25\] ;; esac done  \--- \#\#\#\# Ejercicio 4: Automatización Administrativa y Red **Objetivo:** Comprobar conectividad periódica y gestionar logs 33\. \* **Paso 1: Definir funciones.** Cree limpiar\_logs para reutilizar código de mantenimiento 34, 35\. \* **Paso 2: Bucle infinito.** Use while para la comprobación recurrente 28, 36\. \* **Paso 3: Mensajes estructurados.** Use un **Here Document** para redirigir bloques de error al log 33, 37\. **Solución monitor\_red.sh:** bash \#\!/bin/bash \# Monitoreo de conectividad y limpieza de logs \[33, 38\] limpiar\_logs() { echo "Limpiando archivos temporales..." rm /tmp/\*.log 2\>/dev/null \[33, 39\] } limpiar\_logs while true; do if ping \-c 1 8.8.8.8 \>/dev/null 2\>&1; then echo "$(date): Conexión activa" else \# Redirección mediante Here Document \[33\] cat \<\> \~/error\_red.log ALERTA DE RED: Fecha: $(date) Estado: Servidor DNS 8.8.8.8 inalcanzable. \[40\] EOF fi sleep 60 \[33\] done  *Nota: Para ejecutar este script una sola vez en el futuro, el alumno usaría: at now \+ 1 minute \-f monitor\_red.sh 41, 42\.* \--- \#\#\#\# Ejercicio 5: Personalización del Entorno (.bashrc) **Objetivo:** Configurar alias, funciones y el prompt de forma persistente 43\. \* **Paso 1: Localización.** Estas líneas deben añadirse al archivo \~/.bashrc del usuario 44, 45\. \* **Paso 2: Crear Alias.** Use alias para comandos cortos 46, 47\. \* **Paso 3: Definir el Prompt.** Configure la variable PS1 con caracteres de escape 48, 49\. **Contenido para añadir a \~/.bashrc:** bash \# Personalización profesional del entorno \[43, 50\] \# Alias para listado detallado \[45, 51\] alias ll='ls \-al' \# Función para navegación rápida \[52, 53\] goto() { cd "$1" && ls \-F \[43, 54\] } \# Configuración del Prompt personalizado \[48, 55\] export PS1="\\u@\\h:\[\\w\]\\$ " \# Aplicar cambios inmediatamente: source \~/.bashrc \[3, 56\]  Para que estos ejercicios resulten efectivos, se recomienda que los alumnos utilicen el comando bash \-x para **depurar** sus scripts y observar cómo se expanden las variables y se ejecutan las estructuras paso a paso 57, 58\. ¿Deseas que genere un **cuestionario de autoevaluación** basado en estas soluciones para reforzar lo aprendido?
